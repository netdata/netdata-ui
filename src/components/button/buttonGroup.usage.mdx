# ButtonGroup

Joins buttons into one segmented control. Use it for a small set of related choices or actions.

## When to use

- Pick one option from a short list, such as a time range (`1h`, `6h`, `24h`, `7d`).
- Toggle several filters at once with `isMulti`, such as alert severities.
- Group related actions (`Edit`, `Copy`) by passing `Button` children.
- For more than five or six options, use a `Select` instead.

## Modes

- Single select: pass `items`, `value` and `onChange`. `onChange` receives the clicked item's `value`.
- Multi select: add `isMulti` and pass an array as `value`. `onChange` receives the new array.
- Children: pass `Button` children and no `items`. The group only joins the corners; it holds no state.

## Look

- The selected segment keeps its flavour (green by default). Unselected segments become `hollow` and `neutral`, so only the selection carries colour.
- To colour every segment, pass `danger`, `warning` or `color` in `buttonProps`.
- An item can override props with its own `buttonProps`, and set a native `title`.
- `buttonProps` apply to every segment, so `{ large: true }` gives the 32px size.

## Segmented variant

- `variant="segmented"` draws the items on the same tinted track as contained tabs: a raised selected item, 22px items with 13px text.
- Use it to switch a value in place, such as a time range or chart type. The default joined-button look stays the default.
- It works with `items`, `value`, `onChange` and `isMulti`. `ButtonComponent` is not used, and `buttonProps` go to each native item button (for example `{ disabled: true }`).
- Each item sets `aria-pressed` to show whether it is selected.

<Canvas of={Stories.SegmentedVariant} />

Use `appearance="raised"` with `variant="segmented"` for a raised value picker with a 26px item height. Add `compact` for 22px items and 12px text. The existing segmented and contained-tabs styles remain unchanged.

```jsx
<ButtonGroup
  variant="segmented"
  appearance="raised"
  compact
  aria-label="Node layout"
  items={[
    { label: "All nodes", value: false },
    { label: "Nodes with data", value: true },
  ]}
  value={hasData}
  onChange={setHasData}
/>
```

Item values support strings, numbers and booleans, and labels accept React nodes, including an icon and text in a `Flex`.

Raised items accept `buttonProps.height` for a per-item Flex height override and `buttonProps.monospace`
to use the theme's monospace font. Their default heights remain 26px (or 22px with `compact`).

## Accessibility

- Each segment is a real `button`, reachable by Tab and activated with Enter or Space.
- Pass `aria-disabled: true` or `"true"` in `buttonProps` or an item's `buttonProps` to keep a
  segment focusable while preventing ButtonGroup's default `onChange`. A supplied `onClick` still
  overrides the generated handler.
- The default look does not set `aria-pressed` or a radiogroup role. Give each item a clear label or `title`.
- The segmented variant sets `aria-pressed` on each item and `role="group"` on the track; pass an `aria-label` for the group.

## Do and don't

- Do keep labels short and of similar length.
- Do keep the selection controlled by your own state.
- Don't mix `items` and children; `items` wins.
- Don't use it for navigation between pages. Use tabs.
