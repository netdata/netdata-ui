# Typography

Text and heading components that apply the Netdata font, size, line height, weight and colour. Use them instead of raw tags.

## Font

- The font is IBM Plex Sans, set on each text component, with system sans-serif fonts as a fallback.

## Headings

- `H0` to `H6` are strong (600) by default. Sizes: H0 27px, H1 25px, H2 23px, H3 21px, H4 17px, H5 15px, H6 13px.
- `H0` and `H1` render an `h1`; `H2` to `H6` render `h2` to `h6`. Use `as` when the page outline needs a different level.
- Pass `strong={false}` for regular weight.

## Text

- Sizes: `TextHuge` 25px, `TextBigger` 17px, `TextBig` 15px, `Text` 13px (the regular body size), `TextSmall` 12px, `TextMicro` 11px, `TextNano` 9px, `TextFemto` 8px.
- Text components render a `span` and are regular weight. Pass `strong` for 600.

## Modifiers

- `color` takes a theme colour key. Default is `main` for headings (H0 to H6) and `text` for body text. Use `textLite` for secondary text and status keys only for status.
- `truncate` keeps one line with an ellipsis. The text needs a bounded width to truncate.
- `textAlign`, `textDecoration`, `textTransform`, `whiteSpace`, `wordBreak`, `opacity`, margin and padding are also supported.
- `code` gives an inline code look, e.g. a metric name like `system.cpu`.

## Lists

- `List` and `ListItem` render a `ul` and `li` with outside discs. They support margin, padding and `alignSelf`.

## Accessibility

- Choose headings for document structure, not for size. Use `as` or a different `Text` size when the level and the look differ.
- Don't rely on colour alone to convey status.

## Do and don't

- Do use `Text` for body copy and `TextSmall` for captions and helper text.
- Do keep one `H1` per page.
- Don't set raw font sizes or colours with `style`. Use `fontSize` only when no size in the scale fits.
